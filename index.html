📖 Acerca de este proyecto

Esta base de datos recopila información pública sobre intervenciones militares y políticas de Estados Unidos en el extranjero desde 1775 hasta la actualidad. Los datos provienen de artículos de Wikipedia y otras fuentes verificables.

Objetivo didáctico: Facilitar la comprensión del contexto histórico de las relaciones internacionales. Este proyecto no promueve ninguna posición política; la información se presenta de manera neutral con fines educativos.

Metodología: Los datos fueron extraídos de Wikipedia (ES/EN) y estructurados en formato JSON bilingüe. Cada registro incluye año de inicio/fin, país, descripción y enlace a la fuente original para verificación.
